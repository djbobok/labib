Лабораторная работа 1 — вариант 3
===================================

В папке находятся четыре обязательные программы и программа индивидуального задания № 3.

Файлы:
- FizzBuzz.java — числа от 1 до 500, fizz/buzz/fizzbuzz;
- ReverseArguments.java — разворот строки из аргументов командной строки;
- Fibonacci.java — первые N чисел Фибоначчи;
- Factorial.java — факториал неотрицательного целого числа;
- Variant3Divisible.java — из трех чисел выводит делящиеся на 3 или на 9.

Компиляция всех файлов из этой папки:
javac -encoding UTF-8 FizzBuzz.java ReverseArguments.java Fibonacci.java Factorial.java Variant3Divisible.java

Запуск:
java FizzBuzz
java ReverseArguments make install
java Fibonacci
java Factorial
java Variant3Divisible

Для интерактивных программ введите значения после приглашения в консоли.
Примеры контрольных данных и ожидаемых результатов приведены в отчете.

Проверка: исходники скомпилированы; контрольные примеры из отчета запущены.
Для отображения русских сообщений в консоли Windows используйте UTF-8 (chcp 65001).
